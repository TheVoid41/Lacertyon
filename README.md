# Lacertyon Introduction

Lacertyon is a world building and diplomatic Project. It consists of several different components such as: Lore Drops, Central Lore Drops, National Broadcasts, National Lore Drops, Nation Information Booklets and more. The Project is set on a Planet on which there are many different joinable nations.

## Main Communications

Lacertyon Nations have discord servers you can join which have information regarding lacertyon and the specific nations. Lacertyon Nations are divided into specific categories. A nation being in a specific category is determined by how active it is and how important it is.
