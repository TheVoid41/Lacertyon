# Security Policy

## Supported Versions

The project currently supports the latest released version on the main branch.
Older or unmaintained versions may not receive security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability in Lacertyon, please report it privately and do not open a public GitHub issue.

Preferred methods:
- GitHub Security Advisories 
- Discord Support Ticket on the Lacertyon Discord Server 

Please include:
- A clear description of the issue
- Steps to reproduce it
- The affected URL, page, or endpoint
- Any proof-of-concept details that are needed to understand the issue

## What to Avoid

Please do not:
- Publish the vulnerability publicly before a fix is available
- Access or modify user data beyond what is necessary to confirm the issue
- Perform destructive testing or denial-of-service testing

## Response Expectations

We will aim to acknowledge valid reports As Soon As Possible.

## Scope

This policy applies to the website, application logic, authentication flows, and any related backend services used by Lacertyon.
